# LLM-as-a-Judge for Recommendation Evaluation
 
This is the implementation for the paper:

> Yue Que, Junyi Zhou, Xiaokun Zhang, Haiming Jin, Qiao Xiang, and Chen Ma (2026). LLM-as-a-Judge for Reliable and Explainable Offline Evaluation in Top-K Recommendation. In KDD'26.

## To Start With

In ```judge``` folder we implement the LLM Judge to evaluate recommendation lists generated by recommenders. You can try directly evaluting the prepared lists stored in  ```preprocess``` folder.

1. Firstly, prepare your own LLM model and API and fill them into the  ```api_key```, ```base_url```, and ```llm_name``` in ```judge/parse.py```.

2. Then, run ```run_coat.sh``` and ```run_kuairec.sh``` for each dataset.


Alternatively, in ```src``` folder, you can also train the recommendation model from scratch for each dataset to perform the above evaluation.  

For Kuairec dataset:
```
python train.py --dataset kuairec --model gcn --lr 1e-4 --weight 1e-3 --epoch 500 --save 1 
python train.py --dataset kuairec --model mf --lr 1e-4 --weight 1e-2 --epoch 50 --save 1 
python train.py --dataset kuairec --model lrgccf --lr 1e-5 --weight 5e-3 --epoch 50 --save 1 
python train.py --dataset kuairec --model ngcf --lr 5e-5 --weight 5e-3 --epoch 400 --save 1 
python train.py --dataset kuairec --model neumf --lr 5e-7 --weight 0 --epoch 600 --save 1
python train.py --dataset kuairec --model mgccf --lr 1e-6 --weight 5e-3 --epoch 100 --save 1 
python train.py --dataset kuairec --model simgcl --eps 0.5 --lam 1e-2 --lr 1e-4 --weight 5e-3 --epoch 250 --save 1 
python train.py --dataset kuairec --model caged --lr 5e-4 --weight 5e-3 --lr2 1e-4 --eps_decay 5e-4 --sc_var 1 --beta 0 --epoch 500 --save 1 
python train.py --dataset kuairec --model gtn --lr 1e-4 --weight 7e-3 --lam 5e-4 --epoch 70 --save 1 
```
